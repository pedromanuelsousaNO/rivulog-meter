BLE-C600 diagnostic bridge
Purpose
This page does not guess or save measurements. It only connects to the BLE-C600, lists accessible BLE services/characteristics and records raw packets so the meter protocol can be identified safely.
You can add more service UUIDs later if the diagnostic reveals them.
